1. API Overview
# API Method Endpoint Purpose
1 TDS Setup POST /internal/v1/tds/merchant/{merchant_id}/setup Enable TDS Payment and/or Filing
2 TDS Status GET /internal/v1/tds/merchant/{merchant_id}/status Check TDS enablement status
3 TDS Update PATCH /internal/v1/tds/merchant/{merchant_id}/setup Update TDS settings / disable (same endpoint as setup)
4 Bank Accounts GET x-balances-ext.razorpay.com/v1/accounts?merchant_id={merchant_id} Fetch merchant bank accounts (List Accounts API)
5 Contacts GET /merchant/api/live/contacts?active=1&count=15 Fetch merchant contacts/vendors
6 LDC Certificate POST /internal/v1/tds/merchant/{merchant_id}/contact/{contact_id}/ldc Create LDC certificate for vendor
2. TDS Setup API (Unified)
Purpose

Single API to enable TDS Payment and/or TDS Filing. Business logic determines what to enable based on fields provided.

POST
/internal/v1/tds/merchant/{merchant_id}/setup
Business Logic
Fields Provided Action
Only payment_config Enable TDS Payment only
payment_config + filing_config + merchant_details + responsible_person Enable both TDS Payment & Filing
Only filing_config + merchant_details + responsible_person Enable TDS Filing (Payment must be enabled first)

1. Database Overview
Architecture

The TDS system uses a flexible key-value metadata table for merchant settings, combined with dedicated tables for LDC certificates and audit logging.

Table Purpose Primary Key
tds_merchant_metadata Stores all TDS settings as key-value pairs merchant_id + meta_key
tds_ldc_certificates Stores LDC certificates for vendor contacts id
tds_audit_log Audit trail for all TDS changes id
2. tds_merchant_metadata Table
CREATE TABLE tds_merchant_metadata (
    id              VARCHAR(14)    PRIMARY KEY,
    merchant_id     VARCHAR(14)    NOT NULL,
    meta_key        VARCHAR(50)    NOT NULL,
    meta_value      JSON           NOT NULL,
    created_at      BIGINT         NOT NULL,
    updated_at      BIGINT         NOT NULL,
    deleted_at      BIGINT         NULL,        -- Soft delete timestamp
    
    UNIQUE KEY idx_merchant_key (merchant_id, meta_key),
    INDEX idx_merchant (merchant_id),
    INDEX idx_deleted (deleted_at)
);
Meta Keys
meta_key Purpose meta_value Structure
TDS_PAYMENT_ENABLED Payment enablement flag {"enabled": true/false, "last_changed_at": timestamp}
TDS_PAYMENT_CONFIG TAN and bank account {"tan": "...", "account_number": "..."}
TDS_FILING_ENABLED Filing enablement flag {"enabled": true/false, "last_changed_at": timestamp}
TDS_FILING_CONFIG Filing configuration {"filing_start_date": ts, "quarter": "Q4", "financial_year": "2025-26"}
TDS_MERCHANT_DETAILS Merchant/deductor details {"name": "...", "pan": "...", "city": "...", ...}
TDS_RESPONSIBLE_PERSON Responsible person details {"name": "...", "pan": "...", "designation": "...", ...}
TDS_MONTHLY_SNAPSHOT_* Monthly state snapshot {"snapshot_month": "January", ...}
TDS_QUARTERLY_SNAPSHOT_* Quarterly state snapshot {"snapshot_quarter": "Q4_2025-26", ...}
3. tds_ldc_certificates Table
CREATE TABLE tds_ldc_certificates (
    id                  VARCHAR(14)    PRIMARY KEY,
    merchant_id         VARCHAR(14)    NOT NULL,
    contact_id          VARCHAR(14)    NOT NULL,
    tds_category_id     VARCHAR(10)    NOT NULL,
    certificate_number  VARCHAR(50)    NOT NULL,
    ldc_rate            DECIMAL(5,2)   NOT NULL,
    valid_from          BIGINT         NOT NULL,
    valid_to            BIGINT         NOT NULL,
    file_id             VARCHAR(20)    NULL,
    created_at          BIGINT         NOT NULL,
    updated_at          BIGINT         NOT NULL,
    deleted_at          BIGINT         NULL,        -- Soft delete timestamp
    
    INDEX idx_merchant_contact (merchant_id, contact_id),
    INDEX idx_validity (valid_from, valid_to),
    INDEX idx_category (tds_category_id),
    INDEX idx_deleted (deleted_at)
);
TDS Categories
Category ID Description Standard Rate
194C Contractors 1% / 2%
194J Professional/Technical Services 10%
194H Commission/Brokerage 5%
194I Rent 10%
194A Interest 10%
Overlap Rule

Two LDC certificates for the same contact_id + tds_category_id cannot have overlapping validity periods. A new certificate must start after the previous one expires.

4. tds_audit_log Table
CREATE TABLE tds_audit_log (
    id              VARCHAR(14)    PRIMARY KEY,
    merchant_id     VARCHAR(14)    NOT NULL,
    entity_type     VARCHAR(30)    NOT NULL,
    field_changed   VARCHAR(50)    NOT NULL,
    action          ENUM('ENABLE','DISABLE','UPDATE','CREATE') NOT NULL,
    old_value       JSON           NULL,
    new_value       JSON           NULL,
    changed_by      VARCHAR(50)    NOT NULL,
    changed_by_type ENUM('MERCHANT','ADMIN','SYSTEM') NOT NULL,
    ip_address      VARCHAR(45)    NULL,
    created_at      BIGINT         NOT NULL,
    updated_at      BIGINT         NOT NULL,
    deleted_at      BIGINT         NULL,        -- Soft delete timestamp
    
    INDEX idx_merchant (merchant_id),
    INDEX idx_action (action),
    INDEX idx_created (created_at),
    INDEX idx_deleted (deleted_at)
);
Entity Types
entity_type Description
TDS_SETTINGS Payment/Filing enable/disable flags
PAYMENT_CONFIG TAN and bank account changes
FILING_CONFIG Filing configuration changes
MERCHANT_DETAILS Merchant detail changes
RESPONSIBLE_PERSON Responsible person changes
LDC_CERTIFICATE LDC certificate create/update
5. Common Queries
Check if TDS Payment is Enabled
SELECT meta_value->'$.enabled' AS is_enabled
FROM tds_merchant_metadata
WHERE merchant_id = 'JInBTCIHDIQAOW'
  AND meta_key = 'TDS_PAYMENT_ENABLED';
Get All TDS Settings for Merchant
SELECT meta_key, meta_value, created_at, updated_at
FROM tds_merchant_metadata
WHERE merchant_id = 'JInBTCIHDIQAOW'
ORDER BY created_at;
Get Active LDC for Contact + Category
SELECT *
FROM tds_ldc_certificates
WHERE merchant_id = 'JInBTCIHDIQAOW'
  AND contact_id = 'cont_OxGtNkW8Y1'
  AND tds_category_id = '194C'
  AND status = 'ACTIVE'
  AND UNIX_TIMESTAMP() BETWEEN valid_from AND valid_to;
Get Audit History
SELECT action, field_changed, old_value, new_value, 
       changed_by, FROM_UNIXTIME(created_at) AS changed_at
FROM tds_audit_log
WHERE merchant_id = 'JInBTCIHDIQAOW'
ORDER BY created_at DESC
LIMIT 20;
